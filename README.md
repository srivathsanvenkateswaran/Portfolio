# Portfolio · Srivathsan Venkateswaran

A single-page static portfolio — plain HTML, CSS and JavaScript, no build step
and no dependencies.

The design language is shared with TravelPort, the sibling travel site: warm
paper surfaces, one blue accent, one amber highlighter, Manrope over JetBrains
Mono. Tokens are copied from that project rather than re-picked, so the two
match instead of merely resembling each other.

## Layout

```
index.html   page shell and all prose that is not data
styles.css   tokens, primitives, page styles
data.js      projects, career, links — the source of truth for every card
india.js     baked map geometry, generated by scripts/bake-map.py
render.js    draws projects, career, stats and the atlas from those two files
script.js    scroll reveal, card disclosure, year filter, nav highlight
```

`index.html` carries no project copy at all. To correct a fact, edit `data.js`.

Each project's `status` has to be literally true:

| status | means |
|---|---|
| `running` | deployed and in real use by someone who is not me |
| `live` | deployed and reachable, no claim about users |
| `private` | built and working, no public repo, not deployed |
| `archive` | older public work, still up, not worked on now |

The page prints these in plain English — "In real use", "Deployed", "Built, not
deployed", "Archive".

## Run locally

```sh
python3 -m http.server 3000
# open http://localhost:3000
```

## Checks

```sh
node scripts/check-links.mjs             # structure + link reachability
node scripts/check-links.mjs --offline   # structure only
./scripts/velocity.sh                    # recount the two build figures
python3 scripts/bake-map.py              # regenerate india.js from TravelPort
```

`check-links.mjs` exists because a calling card that links a 404 is worse than
one that says "private". It proves every `repo` field is publicly readable and
that each live link still serves the right site, not just a 200.

## Deploy

Push to `main`. Vercel builds from the repo root with no framework preset and no
build command.
