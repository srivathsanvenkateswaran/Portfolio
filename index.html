OneMetro: the pulse of urban India

An open-source gateway to India's rapid transit systems. A hybrid SVG engine renders each city's network: real WGS84 geographic projection for Chennai, Pune and Ahmedabad, custom schematic grids for Delhi and Mumbai. Sub-second loads, zero runtime network calls, no tracking.
